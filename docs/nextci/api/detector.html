검지기Detectors

검지기 조회와 세션 중 추가·삭제 메서드입니다. 구간 값은 마지막으로 완료된 집계 구간을 기준으로 합니다.Detector queries and session add/remove methods. Interval values refer to the last completed aggregation interval.

비용Cost

조건Conditions

집계 주기 이상 sim_step()으로 진행한 뒤 flush_recordings()를 호출하세요. 기록이 없으면 No detector interval record yet 오류가 발생합니다. 조회 전 get_detector_last_record_available()로 확인할 수 있습니다. 모든 종류가 대수·평균속도·교통량을 제공하며, E2는 점유율·평균/최대 대수, E3는 통행시간을 추가로 제공합니다.

Advance at least one aggregation period with sim_step(), then call flush_recordings(). With no record, No detector interval record yet is raised. Check get_detector_last_record_available() before reading. Every type provides count, mean speed, and flow. E2 also provides occupancy and mean/max vehicle number; E3 adds travel time.

add_detector_raw

변경Change

명세 문자열로 검지기를 추가합니다. 보통은 아래 E1/E2/E3 메서드를 씁니다.

Add a detector from a spec string. Normally use the E1/E2/E3 methods below.

client.add_detector_raw(*, object_id: str = '', spec: str) -> DetectorAddResult
인자Arguments
이름Name타입 · 기본값Type · default의미Meaning
object_id 선택optionalstr = ''검지기 ID. 비우면 서버가 정합니다.Detector ID; empty lets the server choose.

조건Conditions

A detector referencing a missing link or lane is still added, but with enabled=0 and no recorded values. Check enabled in the returned DetectorAddResult.payload.
