타입과 예외Types and errors

서버 오류를 처리하고 검지기 추가 결과를 읽는 방법을 확인하세요.Handle server errors and read detector-add results.

예외와 결과 타입Exceptions and result types

이름Name상위Base설명 · 속성Description · attributes
NextCIErrorRuntimeErrorBase exception for nextci package.
NextCIStatusErrorNextCIErrorRaised when the server responds with a non-zero status. — command, status_code, message

서버가 0 이 아닌 상태 코드로 답하면 NextCIStatusError 가 납니다. status_code 는 대부분 1(일반 오류)이고, 없는 체크포인트를 복원할 때만 2(없음)입니다. message 에 서버의 설명이 들어 있습니다.

A non-zero status from the server raises NextCIStatusError. status_code is 1 (general error) almost everywhere, and 2 (not found) only when restoring a missing checkpoint; message carries the server's explanation.

간단한 사용 예제Quick example

연결된 클라이언트에서 실행하세요.Run with a connected client.

from nextci import NextCIStatusError

try:
    client.restore_checkpoint("nope")
except NextCIStatusError as e:
    print(e.status_code, e.message)
