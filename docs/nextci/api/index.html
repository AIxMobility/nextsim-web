연결과 서버Connection and server

메서드Method반환Returns하는 일What it does
NextCIClient—클라이언트를 만듭니다. 아직 연결하지는 않습니다.Create a client. It does not connect yet.
connectNextCIClient이미 떠 있는 서버에 연결합니다.Connect to a server that is already running.
closeNone연결을 닫습니다. 서버 프로세스는 끄지 않습니다.Close the connection. The server process keeps running.
launch_serversubprocess.Popen[bytes]UnitTestsAPI 를 띄우고, 포트를 열 때까지 기다립니다.Start UnitTestsAPI and wait until it opens its port.
stop_serverNone이 클라이언트가 띄운 서버를 끝냅니다. 3 초 안에 끝나지 않으면 강제로 끝냅니다.Stop the server this client started; kill it if it has not exited within 3 s.
launch_and_connectNextCIClient서버를 띄우고 바로 연결합니다. 가장 흔한 시작 방법입니다.Start the server and connect. The usual way to begin.

시뮬레이션 조회Simulation queries

메서드Method반환Returns하는 일What it does
get_sim_variable_intint정수형 시뮬레이션 변수를 ID 로 직접 읽습니다. 보통은 위의 전용 메서드를 씁니다.Read an integer simulation variable by ID. Normally use the dedicated methods above.
get_sim_variable_stringstr문자열 시뮬레이션 변수를 ID 로 직접 읽습니다.Read a string simulation variable by ID.
get_current_cycleint지금 사이클.Current cycle.
get_total_cycleint시나리오 전체 사이클 수. 10 분 시나리오면 6000.Total cycles in the scenario; 6000 for a 10-minute scenario.
is_finishedbool시나리오가 끝났는지.Whether the scenario has ended.
get_step_intervalintmicro 갱신 간격 (틱 단위). 기본 설정에서 1.Micro update interval in ticks; 1 with the default settings.
get_sim_time_millisint시뮬레이션 경과 시간 (ms) = 사이클 × 100.Elapsed simulation time in ms (cycles × 100).
get_scenario_idint돌고 있는 시나리오 번호.ID of the scenario being run.
get_bgt_cyclesint배경 교통(BGT) 준비 구간의 사이클 수. 시나리오의 BGTduration 에서 옵니다.Cycles of the background-traffic (BGT) warm-up, from the scenario's BGTduration.
get_record_modes_enabledstr켜져 있는 기록 종류 번호를 쉼표로 이은 문자열. 예: 1,2,3,4,5,7,10.Comma-separated IDs of the enabled record types, for example 1,2,3,4,5,7,10.
get_output_pathsstr출력 폴더와 결과 파일 경로. outputDir=…;db=…;vehicleState=…;simulationInfo=…Output folder and result file paths: outputDir=…;db=…;vehicleState=…;simulationInfo=…
get_recommended_flush_intervalint어댑터가 기록을 내보내는 주기 (사이클). 지금은 200.How often the adapter flushes recordings, in cycles; 200 today.
