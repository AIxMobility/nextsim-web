MesoMeso

Meso 링크·차로·셀 조회 메서드입니다. 셀 값은 대상 링크가 현재 meso 모드일 때만 조회할 수 있습니다. micro 모드에서 셀 값을 조회하면 NextCIStatusError가 발생합니다.Meso link, lane, and cell query methods. Cell values are available only while the target link is in meso mode. Querying cell values in micro mode raises NextCIStatusError.
