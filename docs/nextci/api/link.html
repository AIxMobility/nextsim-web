링크Links

링크 정적·동적 상태와 링크 모드 전환 메서드입니다. 차량 관련 조회는 micro 기준이며, meso로 실행 중인 링크에서는 해당 값이 비어 있습니다.Static and dynamic link state and link-mode methods. Vehicle-related queries are micro-oriented; those values are empty on links running in meso mode.

        counts[link] = client.get_link_vehicle_count(link)

        pass

set_link_mode

변경Change

링크 하나를 micro 또는 meso 로 바꿉니다. 지금 NextCI 에서 시뮬레이션을 바꿀 수 있는 유일한 명령입니다.

Switch one link to micro or meso — the only command in NextCI today that changes the simulation.

client.set_link_mode(link_id: int, mode: str) -> str
인자Arguments
이름Name타입 · 기본값Type · default의미Meaning
link_id 필수requiredint링크 ID. get_link_id_list() 로 얻습니다.Link ID, from get_link_id_list().
mode 필수requiredstr"micro" 또는 "meso". 다른 값이면 ValueError."micro" or "meso"; anything else raises ValueError.
반환Returns
str — 예: linkId=20000499;mode=microFor example linkId=20000499;mode=micro.
조건Conditions
링크 위의 차량은 새 모드로 옮겨집니다. meso 로 바꾸면 get_vehicle_count() 와 get_link_* 에서는 빠지고 get_meso_cell_vehicle_count() 로 셉니다.Vehicles on the link move into the new representation. After switching to meso they drop out of get_vehicle_count() and get_link_*, and are counted with get_meso_cell_vehicle_count().
비용Cost
호출마다 엔진의 연결 정보를 다시 계산합니다. 예제 네트워크에서 링크 325 개를 바꾸는 데 약 2 s.Each call recomputes the engine's connection info; switching 325 links in the example network took about 2 s.

간단한 사용 예제Quick example

연결된 클라이언트에서 실행하세요. 표시된 ID는 자신의 네트워크 값으로 바꾸세요.Run with a connected client. Replace shown IDs with values from your network. study_area는 micro로 유지할 링크 ID 집합입니다. 전환할 수 있는 링크는 get_meso_link_id_list()로 확인하세요. study_area is the set of link IDs to keep in micro mode. Use get_meso_link_id_list() to find switchable links.

for link in client.get_meso_link_id_list():
    if link not in study_area:
        client.set_link_mode(link, "meso")
