체크포인트Checkpoints

메모리 체크포인트와 예전 상태 저장 메서드입니다. 메모리 체크포인트는 세션 종료 시 사라지며, 난수 상태를 저장하지 않아 복원 후 실행 결과가 달라질 수 있습니다.In-memory checkpoints and legacy state-save methods. In-memory checkpoints disappear when the session ends. They do not save random-number state, so results can differ after restoring and continuing.

변경Change

지금 상태를 서버 메모리에 이름을 붙여 저장합니다.

Save the current state in server memory under a name.

client.save_checkpoint(checkpoint_id: str = 'default') -> str
인자Arguments
이름Name타입 · 기본값Type · default의미Meaning
checkpoint_id 선택optionalstr = 'default'체크포인트 이름. 같은 이름으로 다시 저장하면 덮어씁니다.Checkpoint name. Saving again under the same name overwrites it.
반환Returns
str — 예: Checkpoint saved: t0For example Checkpoint saved: t0.
조건Conditions
저장하는 것: 사이클, 차량 ID 카운터, 링크의 차량(micro 차로와 모든 meso 셀), 차로·셀별 신호 상태, 모드 시퀀스, 검지기 집계, 출발지·차고지·도착지 대기열. 저장하지 않는 것: 난수 상태.Saved: cycle, vehicle ID counter, vehicles on links (micro lanes and every meso cell), per-lane and per-cell signal state, mode sequence, detector accumulators, source/garage/sink queues. Not saved: random-number state.

메모리 체크포인트의 개수 제한은 없습니다.

There is no count limit for in-memory checkpoints.
