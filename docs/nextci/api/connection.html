연결과 서버Connection and server

클라이언트 생성과 서버 연결·수명 주기 메서드입니다. with 블록을 벗어나면 close()와 stop_server()가 차례로 호출됩니다. 서버는 기본적으로 연결 하나만 받는 ServeOnce 방식으로 실행됩니다.Client creation and server connection and lifecycle methods. Leaving a with block calls close(), then stop_server(). By default, the server runs in ServeOnce mode and accepts a single connection.

launch_server

연결·실행Connection / execution

UnitTestsAPI 를 띄우고, 포트를 열 때까지 기다립니다.

Start UnitTestsAPI and wait until it opens its port.

client.launch_server(binary_path: str | None = None, cwd: str | None = None, *, ready_timeout_sec: float = 120.0) -> subprocess.Popen[bytes]
인자Arguments
이름Name타입 · 기본값Type · default의미Meaning
binary_path 선택optionalstr | None = NoneUnitTestsAPI 실행 파일 경로. 없으면 NEXTSIM_UNIT_TESTS_API, 그다음 기본 후보를 찾습니다.Path to the UnitTestsAPI binary. Without it: NEXTSIM_UNIT_TESTS_API, then the default candidates.
cwd 선택optionalstr | None = None서버 작업 폴더. 여기서 위로 SimulationInput/config.txt 를 찾습니다. 없으면 NEXTSIM_SERVER_CWD, 그다음 Captain/build 또는 Captain.Server working directory; SimulationInput/config.txt is searched upward from here. Without it: NEXTSIM_SERVER_CWD, then Captain/build or Captain.
ready_timeout_sec 선택optionalfloat = 120.0서버가 포트를 열 때까지 기다리는 최대 시간 (s).Longest wait for the server to open its port (s).
반환Returns
subprocess.Popen[bytes] — 서버 프로세스. 이미 이 클라이언트가 띄운 서버가 살아 있으면 그것을 돌려줍니다.The server process; if this client already started one that is alive, that one.
조건Conditions
