와이어 프로토콜Wire protocol

Python 이 아닌 언어에서 붙으려면 이 형식으로 직접 보내면 됩니다. 정의는 Captain/Includes/captain/NextCI/NextCIProtocol.hpp 에 있습니다.

To connect from a language other than Python, send this format directly. It is defined in Captain/Includes/captain/NextCI/NextCIProtocol.hpp.

객체 ID 는 링크가 linkId, 차로가 linkId:laneIndex, Meso 셀이 linkId:laneIndex:cellIndex 입니다. SUBSCRIBE (0x03) · UNSUBSCRIBE (0x04) 는 예약만 되어 있습니다.

Object IDs are linkId for links, linkId:laneIndex for lanes, and linkId:laneIndex:cellIndex for meso cells. SUBSCRIBE (0x03) and UNSUBSCRIBE (0x04) are reserved only.
