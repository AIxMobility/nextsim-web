붐비는 도로의 상태를 1 분마다 기록하기Log the busiest roads every minute

예제 코드와 실행 결과를 따라 작업 흐름을 익힙니다. 출력 수치는 네트워크와 실행에 따라 달라집니다.Follow the example code and output to learn the workflow. Output values vary with the network and run.

네 가지 흔한 작업을 짧은 스크립트로 따라 합니다. 스크립트는 저장소의 NextCI/examples/tutorials/ 에 있고, 각자 서버를 띄웠다가 끝나면 끕니다. 예제 네트워크 bucheon 의 시나리오 0 에서 돌렸으며, 출력은 그때의 예시입니다. 시뮬레이션에 무작위성이 있어 실행할 때마다 값이 조금씩 다릅니다.

Four common jobs, each as a short script. The scripts live in NextCI/examples/tutorials/ in the repository; each starts its own server and stops it at the end. They were run on scenario 0 of the example network bucheon, and the outputs shown are from those runs. The simulation is stochastic, so values differ a little from run to run.

1. 붐비는 도로의 상태를 1 분마다 기록하기Log the busiest roads every minute

5 분 동안 차량이 채워진 뒤 가장 붐비는 링크 세 개를 골라, 시나리오가 끝날 때까지 1 분마다 차량 수와 평균 속도를 CSV 에 씁니다.

After five minutes of fill-up, pick the three busiest links and write their vehicle count and mean speed to a CSV every minute until the scenario ends.

NextCI/examples/tutorials/t1_log_links.py
"""Tutorial 1: log the state of the busiest links to a CSV file every minute."""
import csv

from nextci import NextCIClient, NextCIStatusError


def busiest_links(client, n):
    """The n links with the most vehicles right now."""
    counts = {}
    for link in client.get_link_id_list():
        try:
            counts[link] = client.get_link_vehicle_count(link)
        except NextCIStatusError:        # intersection-internal links cannot be queried one by one
            pass
    return sorted(counts, key=counts.get, reverse=True)[:n]


with NextCIClient().launch_and_connect() as client, open("links.csv", "w", newline="") as f:
    client.sim_step(3000)                # the first 5 min fill the network
    links = busiest_links(client, 3)

    out = csv.writer(f)
    out.writerow(["time_s", "link_id", "vehicles", "mean_speed_mps"])
    while not client.is_finished():
        client.sim_step(600)             # 60 s
        t = client.get_sim_time_millis() / 1000
        for link in links:
            out.writerow([t, link,
                          client.get_link_vehicle_count(link),
                          round(client.get_link_mean_speed_mps(link), 2)])

살펴볼 점What to notice

  • get_link_id_list() 에는 교차로 내부 링크도 들어 있어, 개별 조회를 try 로 감싸고 NextCIStatusError 를 건너뜁니다.get_link_id_list() includes intersection-internal links, so per-link queries sit in a try that skips NextCIStatusError.
  • sim_step(600) 은 60 s 입니다. 1 사이클이 0.1 s 이기 때문입니다.sim_step(600) is 60 s, because one cycle is 0.1 s.
  • is_finished() 가 True 가 되면 반복이 끝납니다. 10 분 시나리오라 5 분 워밍업 뒤 다섯 번 기록합니다.The loop ends when is_finished() turns True; with a 10-minute scenario that is five records after the 5-minute warm-up.
