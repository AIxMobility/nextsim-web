관심 구간만 micro 로, 나머지는 meso 로Micro for the study area, meso for the rest

예제 코드와 실행 결과를 따라 작업 흐름을 익힙니다. 출력 수치는 네트워크와 실행에 따라 달라집니다.Follow the example code and output to learn the workflow. Output values vary with the network and run.

네 가지 흔한 작업을 짧은 스크립트로 따라 합니다. 스크립트는 저장소의 NextCI/examples/tutorials/ 에 있고, 각자 서버를 띄웠다가 끝나면 끕니다. 예제 네트워크 bucheon 의 시나리오 0 에서 돌렸으며, 출력은 그때의 예시입니다. 시뮬레이션에 무작위성이 있어 실행할 때마다 값이 조금씩 다릅니다.

Four common jobs, each as a short script. The scripts live in NextCI/examples/tutorials/ in the repository; each starts its own server and stops it at the end. They were run on scenario 0 of the example network bucheon, and the outputs shown are from those runs. The simulation is stochastic, so values differ a little from run to run.

4. 관심 구간만 micro 로, 나머지는 meso 로Micro for the study area, meso for the rest

가장 붐비는 링크 다섯 개만 micro 로 남기고 나머지 325 개를 meso 로 바꿔, 같은 시점에서 1 분을 돌렸을 때의 계산 시간과 차량 수를 전부 micro 인 경우와 비교합니다. NextSIM 의 하이브리드 방식을 코드로 확인하는 예제입니다.

Keep only the five busiest links micro, switch the other 325 to meso, and from the same moment compare one minute of computation time and vehicle count against all-micro — the hybrid idea of NextSIM, in code.

NextCI/examples/tutorials/t4_hybrid.py
"""Tutorial 4: keep the study area micro, switch the rest to meso, and compare."""
import time

from nextci import NextCIClient, NextCIStatusError


def busiest_links(client, n):
    counts = {}
    for link in client.get_link_id_list():
        try:
            counts[link] = client.get_link_vehicle_count(link)
        except NextCIStatusError:
            pass
    return sorted(counts, key=counts.get, reverse=True)[:n]


def total_vehicles(client, meso_links):
    """Vehicles on micro lanes plus vehicles inside meso cells."""
    n = client.get_vehicle_count()                   # counts micro lanes only
    for link in meso_links:
        for lane in range(client.get_meso_lane_count(link)):
            for cell in range(client.get_meso_section_count(link)):
                n += client.get_meso_cell_vehicle_count(link, lane, cell)
    return n


with NextCIClient().launch_and_connect() as client:
    client.sim_step(3000)
    client.save_checkpoint("t300")
    study = set(busiest_links(client, 5))            # the study area: the 5 busiest links

    # A. one minute with every link micro
    t0 = time.perf_counter()
    client.sim_step(600)
    print(f"all micro : {time.perf_counter() - t0:.2f} s wall, vehicles {client.get_vehicle_count()}")

    # B. from the same moment, everything outside the study area meso
    client.restore_checkpoint("t300")
    meso = [link for link in client.get_meso_link_id_list() if link not in study]
    for link in meso:
        client.set_link_mode(link, "meso")
    t0 = time.perf_counter()
    client.sim_step(600)
    print(f"hybrid    : {time.perf_counter() - t0:.2f} s wall, vehicles {total_vehicles(client, meso)}"
          f"  ({len(meso)} links meso, {len(study)} micro)")
    print("micro only:", client.get_vehicle_count())

실행Run

python3 NextCI/examples/tutorials/t4_hybrid.py

예시 출력Example output

all micro : 0.79 s wall, vehicles 1077
hybrid    : 0.31 s wall, vehicles 968  (325 links meso, 5 micro)
micro only: 132

살펴볼 점What to notice

  • meso 로 바꾼 링크의 차량은 사라지지 않고 셀로 옮겨집니다. 다만 get_vehicle_count() 는 micro 차로 위만 세므로, 전체는 total_vehicles() 처럼 셀을 더해야 합니다 (위 출력의 132 와 968).Vehicles on links switched to meso are not lost; they move into cells. get_vehicle_count() counts micro lanes only, so the total needs the cells added, as total_vehicles() does (132 versus 968 above).
  • 계산 시간은 이 컴퓨터에서 0.79 s → 0.31 s 로 줄었습니다. 컴퓨터와 네트워크에 따라 다릅니다.Computation time dropped from 0.79 s to 0.31 s on this machine; it depends on the machine and the network.
  • 차량 수가 1077 과 968 로 다른 것은 두 모형의 거동이 다르기 때문입니다. 정밀도와 계산 비용 사이의 선택이 바로 이것입니다.The vehicle counts differ (1077 and 968) because the two models behave differently — exactly the trade-off between detail and cost.
  • 링크 325 개를 바꾸는 데 약 2 s 가 걸렸습니다. set_link_mode() 가 호출마다 엔진의 연결 정보를 다시 계산하기 때문입니다.Switching 325 links took about 2 s, because each set_link_mode() call recomputes the engine's connection info.
