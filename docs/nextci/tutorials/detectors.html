검지기로 교통량 · 점유율 · 통행시간 재기Measure flow, occupancy, and travel time with detectors

예제 코드와 실행 결과를 따라 작업 흐름을 익힙니다. 출력 수치는 네트워크와 실행에 따라 달라집니다.Follow the example code and output to learn the workflow. Output values vary with the network and run.

네 가지 흔한 작업을 짧은 스크립트로 따라 합니다. 스크립트는 저장소의 NextCI/examples/tutorials/ 에 있고, 각자 서버를 띄웠다가 끝나면 끕니다. 예제 네트워크 bucheon 의 시나리오 0 에서 돌렸으며, 출력은 그때의 예시입니다. 시뮬레이션에 무작위성이 있어 실행할 때마다 값이 조금씩 다릅니다.

Four common jobs, each as a short script. The scripts live in NextCI/examples/tutorials/ in the repository; each starts its own server and stops it at the end. They were run on scenario 0 of the example network bucheon, and the outputs shown are from those runs. The simulation is stochastic, so values differ a little from run to run.

2. 검지기로 교통량 · 점유율 · 통행시간 재기Measure flow, occupancy, and travel time with detectors

한 링크에 세 종류의 검지기를 붙입니다. 차로마다 E1 으로 교통량을, 한 차로에 E2 로 점유율을, 링크 전체에 E3 로 통행시간을 1 분 단위로 잽니다.

Put all three detector types on one link: E1 per lane for flow, E2 over one lane for occupancy, and E3 around the link for travel time, per minute.

add_detector_e1add_detector_e2add_detector_e3sim_stepflush_recordingsget_detector_flowget_detector_occupancyget_detector_mean_travel_timeget_link_lengthget_link_lane_count
NextCI/examples/tutorials/t2_detectors.py
"""Tutorial 2: measure flow, occupancy, and travel time with E1, E2, and E3 detectors."""
from nextci import NextCIClient

LINK = 20001453                          # 3 lanes, 243.9 m in the example network bucheon

with NextCIClient().launch_and_connect() as client:
    length = client.get_link_length(LINK)
    lanes = client.get_link_lane_count(LINK)

    # E1 at the middle of every lane, E2 over lane 1, E3 around the whole link
    for lane in range(lanes):
        client.add_detector_e1(detector_id=f"e1_{lane}", link_id=LINK,
                               lane_index=lane, pos=length / 2, freq=60.0)
    client.add_detector_e2(detector_id="e2_lane1", link_id=LINK, lane_index=1,
                           pos=10.0, end_pos=length - 10.0, freq=60.0)
    client.add_detector_e3(
        detector_id="e3_link",
        entries=",".join(f"{LINK}:{lane}:5.0" for lane in range(lanes)),
        exits=",".join(f"{LINK}:{lane}:{length - 5:.1f}" for lane in range(lanes)),
        freq=60.0,
    )

    client.sim_step(3000)                # 5 min warm-up
    print("time_s  flow_veh_h lane0/1/2   occupancy_%  travel_time_s")
    for _ in range(5):
        client.sim_step(600)             # 60 s = the detectors' aggregation interval
        client.flush_recordings()        # interval values update after a flush
        flows = [client.get_detector_flow(f"e1_{lane}") for lane in range(lanes)]
        print(f"{client.get_sim_time_millis() / 1000:6.0f}  {flows!s:22}  "
              f"{client.get_detector_occupancy('e2_lane1'):10.1f}  "
              f"{client.get_detector_mean_travel_time('e3_link'):12.1f}")

실행Run

python3 NextCI/examples/tutorials/t2_detectors.py

살펴볼 점What to notice

  • 검지기의 freq=60.0 과 스텝 간격 60 s 를 맞추면, 매 반복마다 새 구간 하나가 끝납니다.With the detectors' freq=60.0 matching the 60 s step, each loop closes exactly one interval.
  • 구간 값은 flush_recordings() 뒤에 갱신됩니다. 빠뜨리면 이전 구간 값이나 No detector interval record yet 오류를 받습니다.Interval values update after flush_recordings(); without it you get the previous interval or No detector interval record yet.
  • 점유율은 E2 에서만, 통행시간은 E3 에서만 채워집니다. E1 에 get_detector_occupancy() 를 부르면 0 이 나옵니다.Occupancy is filled only by E2 and travel time only by E3; get_detector_occupancy() on an E1 returns 0.
  • 교통량 300 veh/h 는 60 s 동안 5 대가 지나갔다는 뜻입니다.A flow of 300 veh/h means 5 vehicles passed in 60 s.
