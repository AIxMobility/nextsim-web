NextCI API 레퍼런스NextCI API reference

NextCIClient 의 공개 메서드 전부를 영역별로 정리했습니다. 시그니처와 와이어 ID 는 nextci 소스에서 자동으로 뽑았고, 설명 · 조건 · 비용은 예제 네트워크에서 실제로 돌려 확인한 내용입니다. 처음이라면 시작하기와 튜토리얼부터 보세요.

Every public method of NextCIClient, by area. Signatures and wire IDs are extracted from the nextci source; descriptions, conditions, and costs were checked by running them on the example network. New here? Start with Getting started and the Tutorials.

연결과 서버Connection and server

NextCIClient 는 with 블록으로 쓰는 것이 기본입니다. 블록을 벗어나면 close() 와 stop_server() 가 차례로 불립니다. 서버는 기본적으로 연결 하나만 받는 ServeOnce 로 뜹니다.
Use NextCIClient in a with block; leaving it calls close() then stop_server(). By default the server runs ServeOnce and accepts a single connection.
