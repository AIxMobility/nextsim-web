NextSIM Simulation 사용자 가이드NextSIM Simulation User Guide

NextSIM 시뮬레이션을 실행하고, 결과를 지도 위에서 재생·분석하는 도구입니다. 차량 하나하나의 움직임부터 링크 단위 혼잡도, 신호 현시, 대중교통 운행, 이벤트 영향까지 시간을 되감아 가며 확인할 수 있습니다.

Runs a NextSIM simulation and replays the result on the map. You can step back and forth through time to inspect anything from the motion of a single vehicle to link-level congestion, signal phases, transit operation, and the effect of incidents.

Simulation 소개What the Simulation is

NextSIM 웹 도구는 두 부분으로 나뉩니다. Editor(/editor)는 네트워크·수요·신호 같은 입력을 만들고, Simulation(/simulation)는 시뮬레이션을 돌려 나온 결과 DB를 재생합니다. 이 문서는 Simulation를 다룹니다 — 입력 편집 방법은 Editor 가이드를 보세요.

The NextSIM web tooling comes in two halves. The Editor (/editor) authors the inputs — network, demand, signals — and the Simulation (/simulation) replays the result database a simulation produced. This document covers the Simulation; for authoring inputs see the Editor guide.

화면 구성: 모든 기능이 상단바에 모여 있습니다 — Inputs(폴더·시나리오 선택), Run(시뮬레이션 실행·DB 로드), 재생 컨트롤(Play/Stop·Speed·Timestep), 검색, Display(표시 옵션), Help. 중앙 지도에서 결과가 재생되고, 링크·노드·차량·정류장을 클릭하면 상세 정보 패널이 열립니다. 폴더를 아직 고르지 않았다면 지도 자리에 No network loaded 카드와 Open Inputs 버튼이 표시됩니다.

Layout: everything lives in the top bar — Inputs (folder and scenario selection), Run (launch a simulation, load a DB), the playback controls (Play/Stop, Speed, Timestep), search, Display, and Help. Results replay on the central map; clicking a link, node, vehicle, or station opens a detail panel. Before you pick a folder, the map area shows a No network loaded card with an Open Inputs button.

Setup 실행과 결과 로드Running and loading results

  1. NextSIM 을 설치해 서버를 띄운 뒤(설치 가이드) http://localhost:8000/simulation 를 엽니다 (/ 기본 경로도 Simulation).
  2. 상단바 Inputs를 눌러 Folder에서 네트워크 폴더를 선택합니다 — 지도에 네트워크가 그려집니다.
  3. 상단바 Run 패널을 열고 Target scenario에서 재생할 시나리오를 선택합니다 — 시간 범위 등 시나리오 정보가 바로 아래 카드에 표시됩니다. (시나리오 선택은 Inputs 가 아니라 Run 패널에 있습니다.)
  1. Install NextSIM and start its server (installation guide), then open http://localhost:8000/simulation (the bare / path also serves the Simulation).
  2. Click Inputs in the top bar and pick a network folder under Folder — the network is drawn on the map.
  3. Open the Run panel in the top bar and pick the scenario to replay under Target scenario — its time range and other details appear in the card just below. (Scenario selection lives in the Run panel, not in Inputs.)
시나리오 선택은 재생 전에. 이벤트의 시각은 선택한 시나리오의 시작 시각 기준 오프셋으로 해석됩니다. 시나리오를 바꾸면 이벤트가 자동으로 다시 해석되므로, 재생 전에 목표 시나리오를 먼저 고르는 편이 안전합니다.
Pick the scenario before you replay. Event times are resolved as an offset from the selected scenario's start time. Switching scenarios re-resolves them automatically, so choose the target scenario first.

방법 A — 에디터에서 만든 입력으로 바로 실행Option A — run straight from edited inputs

상단바 Run 버튼을 누르면 실행 패널이 열립니다.

The Run button in the top bar opens the run panel.

  • Route generation — 실행 전에 경로를 생성할지 선택합니다: RouteGenerator(차량·PT 경로), PaxRouteGenerator (대중교통 승객의 역쌍 경로). 입력을 바꾸지 않았다면 꺼서 시간을 아낄 수 있습니다.
  • Scenario time — 선택한 시나리오의 시작·종료 시각을 실행 직전에 바로 조정할 수 있습니다.
  • Run Selected Network — 파이프라인을 실행합니다: RouteGenerator → (PaxRouteGenerator, 켠 경우) → Simulation → DB load. 단계별 진행 상태와 진행률 막대가 표시되고, 완료되면 결과가 자동으로 로드됩니다. (엔진 빌드는 웹 파이프라인에서 빠졌습니다 — 미리 빌드된 바이너리를 씁니다.)
  • Cancel Run — 실행 중에만 나타나는 버튼으로, 확인을 거쳐 진행 중인 단계의 프로세스를 즉시 종료합니다. 부분 출력은 버려지고 마지막으로 완료된 결과는 그대로 남습니다. 시뮬레이션이 이미 끝나 결과를 마무리하는 DB load 단계는 취소할 수 없습니다.
  • Route generation — whether to regenerate routes first: RouteGenerator (vehicle and transit routes) and PaxRouteGenerator (station-pair routes for transit passengers). Turn them off to save time when the inputs have not changed.
  • Scenario time — adjust the selected scenario's start and end time right before launching.
  • Run Selected Network — runs the pipeline RouteGenerator → (PaxRouteGenerator, if enabled) → Simulation → DB load. Per-stage status and a progress bar are shown, and the result loads automatically when it finishes. (Building the engine is not part of the web pipeline — it uses the pre-built binary.)
  • Cancel Run — shown only while a run is in progress; after a confirmation it stops the current stage's process immediately. Partial output is discarded and the last completed result stays available. The final DB load stage, which only packages an already finished simulation, cannot be cancelled.

Live preview (delayed) 를 켜 두면(기본) 시뮬레이션이 끝나기 전에도 이미 디스크에 확정된 구간부터 재생할 수 있습니다. 타임라인 옆에 PREVIEW · playable to N s 배지가 뜨고, 확정 구간이 늘어나면 슬라이더 범위도 따라 늘어납니다. 엔진의 실제 진행보다 이벤트 청크 하나(수십 초)만큼 늦게 따라가며, 재생이 구간 끝에 닿으면 멈추지 않고 새 데이터를 기다립니다. 정류장 승객 배지는 미리보기에서는 표시되지 않고 최종 로드 때 나타납니다. 실행이 끝나면 최종 결과가 같은 시점에서 이어서 로드됩니다.

With Live preview (delayed) on (the default) you can start replaying the part of the run already confirmed on disk before the simulation finishes. A PREVIEW · playable to N s badge appears next to the timeline and the slider range grows as more of the run is confirmed. The preview lags the engine by about one event chunk (tens of seconds); when playback reaches the end of the confirmed range it waits for new data instead of stopping. Station passenger badges are not shown in the preview; they appear with the final load, which resumes at the same time position when the run completes.

실행 중에는 네트워크를 바꿀 수 없습니다. Inputs 의 폴더 선택은 실행이 끝날 때까지 잠깁니다 — 바꾸면 실행 중인 네트워크의 궤적이 다른 지도 위에 그려지기 때문입니다. 결과에는 네트워크 폴더·시나리오·작업 ID가 함께 기록되며(스토어 metadata 와 결과 DB 의 NextSimRunInfo 테이블), 결과를 열 때 지도의 네트워크와 다르면 재생을 막고 알림을 띄웁니다. 그 자리에서 기록된 네트워크로 전환해 이어 열 수 있습니다.
The network cannot be changed mid-run. The folder selector in Inputs is locked until the run finishes — switching would draw the running network's trajectories on a different map. Every result records its network folder, scenario and job id (in the store metadata and in the NextSimRunInfo table of the result DB); when a result is opened on a different network, playback is blocked and a dialog explains the mismatch, offering to switch to the recorded network and continue.
실행 중에는 페이지를 새로고침하지 마세요. 서버 작업은 계속 돌지만 화면이 그 작업에 다시 붙지 않습니다 — 진행률도, 완료 후 자동 결과 로드도 사라집니다. 그 경우 결과 DB를 아래 방법 B로 직접 열어야 합니다.
Don't reload the page mid-run. The server job keeps going, but the UI does not reattach to it — you lose the progress display and the automatic result load. You would then have to open the result DB by hand via Option B below.

방법 B — 기존 결과 DB 열기Option B — open an existing result DB

같은 Run 패널의 Select DB file로 이미 갖고 있는 결과 파일(.db / .sqlite / .sqlite3)을 선택합니다. 이 경로는 파일을 통째로 읽어들인 뒤 재생이 시작되며 512 MB 까지만 받습니다. 시간 구간별 스트리밍 로드는 서버에서 직접 실행한 경우(방법 A)에만 동작합니다.

Use Select DB file in the same Run panel to open a result file you already have (.db / .sqlite / .sqlite3). This path reads the whole file before playback can start and is capped at 512 MB. Chunked streaming over the time axis only applies to runs launched from the server (Option A).

The shortcuts work only with a result DB loaded and no text field focused. When zoomed far out, vehicles give way to the heatmap — see the FAQ.

Link heatmap의 CI는 밀도 지수(차로당 밀도 ÷ 80 veh/km/lane)와 속도저하 지수(1 − 평균속도 ÷ 자유속도) 중 큰 값입니다. 재생 시점에 따라 실시간으로 갱신됩니다. 이벤트 테이블에 속도(spd) 컬럼이 없는 옛 DB 에서는 밀도 지수만 쓰고, Meso link state 는 차량 대수로 구한 밀도 지수만 씁니다. 지도 아래 범례의 마지막 줄이 지금 쓰이는 계산식을 그대로 보여줍니다.

For Link heatmap, CI is the larger of a density index (per-lane density ÷ 80 veh/km/lane) and a speed-drop index (1 − mean speed ÷ free-flow speed), updated live as playback advances. Older DBs whose event table has no speed (spd) column fall back to the density index alone, and Meso link state uses only the density index derived from vehicle counts. The last line of the on-map legend always shows the formula currently in use.

BIMS 버스 정보 관리(BIMS)Bus Information Management System (BIMS)

결과 DB가 로드되면 버스·정류장·노선의 운영 정보를 볼 수 있습니다. 평상시 화면은 그대로이며, 다음 세 곳에서 들어갑니다.

Once a result DB is loaded, bus, station and route operations can be inspected. The normal map stays unchanged; BIMS opens from three places.

  • 버스 클릭 → 차량 정보 패널의 BIMS 버튼 — Bus Information 모달: 현재 재차·혼잡도, 이전/다음 정류장, 다음 정류장까지 거리, 도착 예측(예측과 실제 병기), 운행 진행률. 탭: Overview(노선 스트립과 같은 노선의 다른 버스), Passengers(승하차·재차 프로파일), Stops(정류장별 도착·출발·정차·승하차·배차간격), History(속도·재차· 정차·구간 통행시간 그래프).
  • 정류장 클릭 — Station Information 모달: 대기 승객, 누적 승하차, 서비스 대수, 평균 정차시간, 평균 배차간격과 Upcoming / Recent buses(Approaching·En Route·At Stop·Departed). 탭: Arrivals, Waiting Passengers, Lines, Charts(대기 인원·승하차·도착·정차·배차간격 시계열). View Approaching Buses로 이 정류장으로 오는 버스만 지도에서 강조합니다. 헤더의 경유 노선 목록은 Routes (N) 토글로 펼치며 기본은 접힌 상태입니다.
  • 상단바 BIMS 버튼 — 관제 대시보드: KPI(운행 버스, 노선, 승객, 평균속도, 평균 배차간격, bunching, 이상상황 수), Fleet Status(상태 필터: Running / At Stop / Delayed / Bunched / Finished), Route Performance, Station Status(지도 정류장을 상태 색으로 표시), Issues(bunching·과대 배차간격·과밀·장기 정차·장기 대기·저속 자동 탐지). 표의 행을 누르면 지도가 그 객체로 이동하고 모달이 열립니다. 톱니 버튼으로 임계값을 조정합니다.
  • Click a bus → BIMS button in the vehicle panel — Bus Information modal: occupancy, onboard passengers, previous/next stop, distance to next stop, estimated arrival (predicted and actual side by side) and trip progress. Tabs: Overview (route strip with the other buses of the route), Passengers, Stops (arrival, departure, dwell, board, alight, headway per stop) and History (speed, load, dwell, segment time).
  • Click a station — Station Information modal: waiting passengers, total boarding/alighting, buses served, average dwell and headway, and Upcoming / Recent buses (Approaching, En Route, At Stop, Departed). Tabs: Arrivals, Waiting Passengers, Lines, Charts. View Approaching Buses highlights only the buses heading to this station. The routes serving the station are behind a Routes (N) toggle in the header, collapsed by default.
  • BIMS button in the top bar — the operations dashboard: KPIs, Fleet Status with filters, Route Performance, Station Status (stations coloured by state on the map) and Issues (automatic detection of bunching, excessive headway, overcrowding, long dwell, long waiting and slow buses). Clicking a row moves the map to that object and opens its modal. The gear button adjusts thresholds.

BIMS 창은 기본으로 화면 중앙에 뜨지만, 헤더의 Dock 버튼으로 우측 패널에 붙일 수 있습니다(선택은 브라우저에 저장). Follow·Focus·Highlight처럼 지도를 봐야 하는 동작을 누르면 자동으로 도킹됩니다. 대시보드는 왼쪽 가장자리를 끌어 폭을 조절하고, 두 번 클릭하면 기본 폭으로 돌아갑니다. 시점 표기는 시나리오 시각 (HH:MM:SS)이며 상단바의 Timestep 옆에도 같은 시각이 표시됩니다. 네트워크 폴더에 ptNames.json({"stations": {"30000123": "KAIST"}, "routes": {"1": "102"}}) 을 두면 ID 대신 이름이 표시됩니다.

Route ID·Bus ID·Station ID는 어디서나 칩으로 표시되며 클릭하면 해당 뷰로 이동합니다(브레드크럼으로 되돌아갑니다). Route 뷰의 Highlight on map은 노선을, Show all buses는 운행 중인 버스를 지도에 강조하고, Charts 탭에 배차간격 추이·시간-거리(Marey) 다이어그램·재차 프로파일이 있습니다. 검색창에 line:102처럼 입력하면 노선 뷰가 열립니다.

The BIMS window opens centered by default; the Dock button in its header pins it to the right side (remembered in the browser). Actions that need the map, such as Follow, Focus and Highlight, dock it automatically. Drag the dashboard's left edge to resize it; double-click restores the default width. Times are shown as scenario clock (HH:MM:SS), also next to Timestep in the top bar. Put a ptNames.json ({"stations": {"30000123": "KAIST"}, "routes": {"1": "102"}}) in the network folder to show names instead of IDs.

Route, bus and station IDs are chips everywhere; clicking one switches the view (breadcrumbs go back). In the Route view, Highlight on map emphasises the route and Show all buses its buses; the Charts tab holds headway over time, a time–distance (Marey) diagram and the load profile. Typing line:102 in the search box opens the route view.

데이터 한계. 재차 인원은 정류장 승하차 기록의 누적(승차−하차)으로 계산하며, 버스 정원은 입력에 없어 차종별 기본값(NB/AB 50, TRT 80)을 가정합니다. 계획 시각표가 없어 지연은 "배차간격 과대 또는 저속" 플래그로 정의합니다. 실행 중 미리보기에서는 정류장 이벤트를 best-effort로 읽어 일부만 보일 수 있습니다.
Data limits. Onboard counts are cumulative boardings minus alightings from station events; bus capacity is not in the inputs, so a per-type default (NB/AB 50, TRT 80) is assumed. There is no planned timetable, so "Delayed" means excessive headway or a slow segment. During the run preview, station events are read best-effort and may be incomplete.

위성 배경Satellite basemap

Display 패널의 Satellite basemap 에서 네트워크 아래에 위성/항공사진을 깔 수 있습니다. 결과를 실제 지형과 함께 보여줄 때 씁니다. 에디터와 같은 기능이며 정합값도 공유합니다.

The Satellite basemap group in the Display panel puts satellite or aerial imagery under the network — useful when presenting results against real geography. It is the same feature as in the Editor and shares its alignment data.

  • Esri Satellite — 키 없이 바로 쓸 수 있는 전 세계 위성영상.
  • VWorld Aerial — 국내 최고 해상도 항공영상. vworld.kr 에서 무료 인증키를 발급받아(사용 도메인에 접속 주소 등록) Key 칸에 넣습니다.
  • Opacity — 배경이 진하면 도로가 묻히므로 슬라이더로 조절합니다.
  • Esri Satellite — worldwide imagery, no key required.
  • VWorld Aerial — the highest-resolution aerial imagery for Korea. Get a free key at vworld.kr (register the address you serve from) and paste it into the Key field.
  • Opacity — dial the imagery back so the roads stay readable.

네트워크 좌표는 원점이 bbox 남서 모서리인 국소 미터 좌표라 그 자체로는 지구상 위치를 알 수 없습니다. 에디터가 basemap.json → osm_import.json → 노드의 osm_lat/osm_lon → nodelink_import.json 순으로 정합을 자동 탐색하며, 결과는 패널 아래 상태줄에 표시됩니다. 정합이 없는 네트워크는 에디터에서 한 번 맞춰 저장하면 Simulation에서도 그대로 복원됩니다.

Network coordinates are local metric with the origin at the bounding box's south-west corner, so they carry no earth position on their own. The tooling looks for a georeference in this order — basemap.json, osm_import.json, osm_lat/osm_lon tags on nodes, then nodelink_import.json — and reports what it found in the status line under the panel. For a network with none of those, align it once in the Editor and save; the Simulation restores the same alignment.

Analyze 시나리오 요약Scenario summary

Once a result DB is loaded, Scenario Summary in the Run panel opens a summary view. FAQ · 문제 해결FAQ & troubleshooting

차량이 안 보여요I can't see any vehicles

  • 결과 DB가 로드되었는지(Run 패널의 상태 표시), 재생 시점이 시나리오 시간 범위 안인지 확인하세요.
  • Display의 Micro vehicles / Meso vehicles 체크가 꺼져 있지 않은지 확인하세요.
  • 큰 DB는 구간별로 로드됩니다 — 방금 이동한 시점의 데이터가 아직 로드 중일 수 있습니다.
  • 아주 많이 축소한 상태에서는 차량 한 대가 1픽셀 미만이 되어, 대신 링크 혼잡도 히트맵이 표시됩니다(집계 데이터가 있는 경우). 조금 확대하면 차량이 돌아옵니다.
  • Check that a result DB is loaded (status in the Run panel) and that the current time is inside the scenario's range.
  • Check that Micro vehicles / Meso vehicles are still enabled in the Display panel.
  • Large DBs load in chunks — the data for the time you just jumped to may still be loading.
  • When zoomed very far out a vehicle is under one pixel, so the link congestion heatmap is drawn instead (where aggregate data exists). Zoom in a little and the vehicles return.

차량이 축소하면 사라지는 이유는?Why do vehicles thin out when I zoom out?

차량 표시는 두 기준으로 자동 조절됩니다. 화면에서 차량 한 대가 1픽셀보다 작아지면 개별 차량 대신 링크 혼잡도 히트맵이 더 정확한 표현이라 그쪽으로 바뀝니다(대체할 집계 데이터가 없으면 바뀌지 않습니다). 그리고 화면 안 차량이 6,000대를 넘으면 일부만 표본으로 그려 프레임률을 지킵니다. 도시 전체를 한 화면에 담는 정도의 배율에서는 대부분 그대로 다 보입니다.

Vehicle drawing adapts on two axes. When a vehicle would be smaller than one pixel on screen, the link congestion heatmap is the more accurate picture and is drawn instead (this substitution is skipped when there is no aggregate data to show). Separately, when more than 6,000 vehicles are in view, a sample is drawn to hold the frame rate. At a zoom that fits a whole city on screen you normally still see all of them.

큰 네트워크에서 지도가 느려요The map is slow on a large network

네트워크는 규모와 무관하게 항상 캔버스로 그려지며, 뷰포트 컬링과 배율별 LOD를 써서 수만 링크 규모까지 부드럽게 동작합니다. 차량은 전용 레이어에서 WebGL2 로 그리며, 지원하지 않는 브라우저에서는 Canvas 2D 로 자동 대체됩니다. 렌더 차이를 확인해야 할 때만 브라우저 콘솔에서 localStorage.setItem('nextsim-network-canvas','off') 로 예전 SVG 경로를 켤 수 있습니다(디버깅용). 반대로 'on' 을 넣는 것은 이제 의미가 없습니다 — 기본이 이미 캔버스입니다.

The network is always drawn on canvas regardless of size, using viewport culling and zoom-based level of detail; it stays smooth into the tens of thousands of links. Vehicles are drawn on their own layer with WebGL2, falling back to Canvas 2D on browsers without it. For debugging a rendering difference you can switch back to the old SVG path from the browser console with localStorage.setItem('nextsim-network-canvas','off'). Setting it to 'on' now does nothing — canvas is already the default.

이벤트가 지도에 안 나타나요Events don't show on the map

  • Display의 Events 가 켜져 있는지 확인하세요.
  • 이벤트는 활성 시간대에만 그려집니다. 이벤트 시각은 선택한 시나리오의 시작 시각 기준 오프셋으로 해석되므로, 예를 들어 08:00 시작 시나리오에서 08:05에 시작하는 이벤트는 재생 300초 지점부터 보입니다.
  • 시나리오를 바꾸면 이벤트가 새 기준으로 다시 해석됩니다 — 재생 전에 목표 시나리오를 먼저 고르세요.
  • Check that Events is enabled in the Display panel.
  • Events are drawn only while they are active. Their times are offsets from the selected scenario's start, so an event starting at 08:05 in a scenario that starts at 08:00 appears 300 s into playback.
  • Switching scenarios re-resolves event times — pick the target scenario before replaying.

지도가 안 움직여요The map won't pan

Pan by dragging with the middle mouse button. Clicking the minimap also moves the view.
