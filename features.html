기능Features

NextSIM이 제공하는 계산 방식과 기능을 소개합니다. 화면 사용 방법은 사용자 가이드에서 자세히 안내합니다. ‘소스 빌드’ 표시가 있는 기능은 Windows 설치 파일과 ZIP 배포판에 포함되어 있지 않으므로, 소스 코드를 직접 빌드해야 사용할 수 있습니다.

What NextSIM computes and what it can do. The user guide explains how to use each screen. Features marked “source build” are not in the Windows installer or the ZIP package; build from source to use them.

필요한 곳만 차량 단위로 계산합니다Vehicle-level detail only where it matters

링크와 시간대마다 적용할 모형을 따로 지정할 수 있으며, 두 모형이 만나는 경계에서는 엔진이 차량을 한 모형에서 다른 모형으로 자동으로 옮깁니다. NextCI를 사용하면 시뮬레이션 도중에도 링크의 모형을 바꿀 수 있습니다.

Choose the model per link and per time period; at the boundary the engine moves vehicles from one model to the other. With NextCI you can also switch a link's model while the simulation runs.

대중교통Public transit

버스·TRT·트램·철도 노선을 도로 교통과 같은 네트워크에서 계산합니다. 승객 수요를 입력하면 승객이 정류장에서 기다렸다가 차량에 타고 내리는 과정까지 시뮬레이션합니다.

Run 모드의 BIMS 화면에서는 정류장마다 기다리는 승객 수, 승하차 인원, 차내 인원이 시간에 따라 어떻게 변하는지 확인할 수 있습니다.

Bus, TRT, tram, and rail lines run in the same network as road traffic. With passenger demand, passengers wait at stops and board and alight vehicles.

The BIMS view in Run mode shows how waiting, boarding, alighting, and on-board passengers change over time at each stop.

신호Signals

교차로마다 신호 현시와 신호 계획을 정의하고, 시간대별 운영 계획(TOD)으로 시간대에 따라 다른 계획을 적용합니다.

결과를 재생할 때는 실행에 사용한 시나리오를 기준으로 신호 상태를 표시합니다.

Define phases and signal plans per junction, and apply different plans by time of day with TOD schedules.

Replays show signal states for the scenario that produced the result.

가상 검지기Virtual detectors

E1(지점)·E2(구간)·E3(영역) 검지기를 네트워크에 설치하면 교통량, 점유율, 통행시간을 현장 관측 자료와 같은 형식으로 기록합니다.

시뮬레이션 결과를 실측 자료와 비교하거나, 대안별 지표를 같은 기준으로 집계할 때 사용할 수 있습니다.

E1 (point), E2 (section), and E3 (area) detectors record flow, occupancy, and travel time in the same form as field data,

so results can be compared with measurements, or alternatives can be scored on the same terms.

실제 도로망 가져오기Real road networks

국가표준 노드링크 데이터나 OpenStreetMap 데이터에서 도로망을 불러와 네트워크를 만든 뒤, 차로와 교차로 연결을 바로 편집할 수 있습니다.

테스트용 무작위 네트워크를 생성할 수도 있고, 네트워크를 ZIP 패키지로 내보내 다른 사람과 공유할 수도 있습니다.

Build a network from Korea's standard node-link data or OpenStreetMap, then edit lanes and junction connections right away.

You can also generate a random network for testing and export a network as a ZIP package to share it.

동적 통행 배정(DTA)Dynamic traffic assignment (DTA)

시뮬레이션을 반복 실행하면서 기점과 종점 사이의 경로 선택 비율이 수렴할 때까지 통행을 배정합니다.

반복할 때마다 수렴 지표가 어떻게 변하는지, 링크별·경로별 결과가 어떻게 달라지는지 웹 화면에서 확인할 수 있습니다.

Repeat the simulation until route shares between origins and destinations converge.

The browser shows how the convergence measure and the link and route results change from one iteration to the next.

NextCINextCI 소스 빌드source build

NextCI는 TCP 통신으로 시뮬레이션을 외부에서 제어하는 인터페이스입니다. Python 클라이언트로 시뮬레이션을 한 스텝씩 진행하면서 링크·차로·셀·검지기 상태를 조회하고, 링크의 계산 단계를 micro와 meso 사이에서 바꿀 수 있습니다.

강화학습 환경을 구성하거나 다른 시뮬레이터와 연동하는 실험에 사용할 수 있습니다. 함수 88개를 레퍼런스로 정리했고, 따라 해 볼 수 있는 튜토리얼 4편을 제공합니다.

NextCI controls the simulation from outside over TCP. With the Python client you step the simulation, query links, lanes, cells, and detectors, and switch links between micro and meso.

Use it to build reinforcement-learning environments or to couple NextSIM with other simulators. The reference covers 88 functions, and four tutorials walk through common tasks.

체크포인트Checkpoints 소스 빌드source build

원하는 시점의 시뮬레이션 상태를 저장해 두고 언제든 그 시점으로 되돌아갈 수 있습니다. 같은 시점에서 여러 제어안을 각각 실행하여 결과를 비교할 수 있습니다.

체크포인트는 난수 상태를 저장하지 않으므로, 되돌아간 뒤의 결과는 실행할 때마다 조금씩 다를 수 있습니다.

Save the simulation state at any moment and return to it later, so several control strategies can be run from the same point and compared.

Checkpoints do not store the random-number state, so runs after a restore may differ slightly.

브라우저에서 쓰는 화면The browser screens

입력 데이터를 만드는 Edit 모드와 시뮬레이션을 실행하고 결과를 재생하는 Run 모드를 하나의 화면에서 전환하며 사용합니다. 화면별 사용 방법은 사용자 가이드에서 확인할 수 있습니다.

One screen switches between Edit mode, where you build the inputs, and Run mode, where you run the simulation and replay the result. The user guide explains each screen.

지원 환경Platforms

시뮬레이션 엔진은 C++17과 OpenMP로 작성되어 여러 CPU 코어를 사용합니다. 어떤 방법으로 설치하든 AVX2를 지원하는 x86-64 CPU가 필요합니다.

The engine is written in C++17 with OpenMP and uses several CPU cores. Every install method needs an x86-64 CPU with AVX2.
