도시 전체는 빠르게, 관심 구간은 차량 한 대까지. The whole city, fast. The part you care about, car by car.

KAIST AIxMobility Lab 이 만든, 중시(meso)와 미시(micro) 모형을 한 네트워크 안에서 함께 돌리는 하이브리드 교통 시뮬레이터. 입력 편집부터 실행, 결과 재생까지 브라우저에서 끝납니다.

From the KAIST AIxMobility Lab: a hybrid traffic simulator that runs mesoscopic and microscopic models side by side in one network, with authoring, running, and replay all in the browser.

도시 전체를 차량 단위로 돌리면 느리고, 전부 집계 모형으로 돌리면 교차로 하나의 거동을 볼 수 없습니다. NextSIM 은 링크마다, 시간대마다 모형을 고르고 경계에서 차량 표현을 자동으로 바꿉니다.

Car by car, a whole city is slow; in aggregate, the one intersection you study disappears. NextSIM picks the model per link and per period, and converts vehicles at the boundary automatically.

하이브리드 해상도Hybrid resolution

링크별·시간대별로 micro/meso 를 지정합니다. 경계 변환은 엔진이 처리합니다.

Choose micro or meso per link and per period; the engine handles the boundary.

대중교통 통합Transit built in

버스·TRT·트램·철도 노선과 승객 수요를 함께 돌리고, 정류장·재차 인원을 BIMS 로 봅니다.

Bus, TRT, tram, and rail lines with passenger demand, and stops and loads in a BIMS view.

신호 제어Signal control

현시·플랜·시간대(TOD) 기반 신호를 편집하고 실시간 제어와 연동합니다.

Phases, plans, and time-of-day schedules, with a hook for real-time control.

가상 검지기Virtual detectors

E1(단면)·E2(구간)·E3(영역) 검지기로 실제 관측과 같은 형식의 값을 모읍니다.

E1 point, E2 section, and E3 area detectors collect field-style observations.

TCP 로 스텝 단위 실행·상태 조회. 강화학습이나 공동 시뮬레이션에 붙이는 Python 클라이언트를 제공합니다.

Step the simulation and query state over TCP — a Python client for RL and co-simulation.

Editor

시뮬레이션 입력을 지도 위에서 직접 만들고 고칩니다. 파일 형식을 몰라도 됩니다.

Build and edit simulation inputs directly on the map — no need to know the file formats.

  • 도로망·차로·교차로 연결 편집, 표준노드링크 / OSM 가져오기
  • OD 수요 행렬, 시간대별 micro/meso 모드 지정
  • 신호 현시·플랜·TOD, 정류장·대중교통 노선, 돌발 이벤트
  • 저장할 때마다 자동 백업, 언제든 복원
  • Roads, lanes, and connections; import from node-link or OSM
  • OD demand matrices; micro/meso mode per period
  • Signal phases, plans, TOD; stations, transit lines, incidents
  • Every save is backed up and can be restored

Simulation

시뮬레이션을 실행하고, 결과를 지도 위에 시간축을 따라 재생하며 읽습니다.

Run a simulation, then replay and read its result on the map along the timeline.

  • 실행 중에도 진행 상황을 미리 보는 라이브 프리뷰
  • 재생 속도 조절, 링크 혼잡도 히트맵과 범례
  • 차량·링크·정류장 클릭 조회, 시나리오 요약 통계
  • 버스 운행 정보(BIMS): 정류장별 대기·승하차·재차 인원
  • Live preview of a run while it is still going
  • Playback speed; link congestion heatmap with a legend
  • Click any vehicle, link, or stop; scenario summary statistics
  • Bus information (BIMS): waiting, boarding, on-board per stop

설치 방법은 네 가지. 어느 쪽이든 끝나면 브라우저에 같은 Editor · Simulation 이 열립니다.

Four ways to install. Each ends with the same Editor and Simulation in your browser.

가장 쉬움Easiest

Windows 설치 파일Windows installer

설치 마법사만 따라가면 됩니다. Python · WSL · Docker 불필요.

Just run the installer. No Python, WSL, or Docker.

NextSim-Setup-v1.1.exe 모든 OSAny OS

Docker

명령 한 줄로 엔진 빌드부터 웹 서버까지. 소스 저장소 권한이 필요합니다.

One command from engine build to web server. Needs source repository access.

docker compose up --build 컴파일 불필요No compiler

Linux · WSL 배포판Linux · WSL package

미리 빌드된 ZIP 을 풀고 스크립트 하나 실행.

Unpack the prebuilt ZIP and run one script.

./start_web.sh 개발자용For developers

소스에서 빌드Build from source

엔진 수정 · NextCI 연동이 필요할 때. 소스 저장소 권한이 필요합니다.

To change the engine or use NextCI. Needs source repository access.

cmake --preset release -S Captain

모든 방법에 AVX2 를 지원하는 x86-64 CPU(2013년 이후 인텔·AMD 대부분)가 필요합니다.

Every method needs an x86-64 CPU with AVX2 (most Intel and AMD CPUs since 2013).
