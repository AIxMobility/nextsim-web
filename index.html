설치하기Install

도시 전체를 빠르게 계산하면서, 필요한 구간은 차량 한 대 단위로 정밀하게 분석합니다. The whole city, fast. The part you care about, car by car.

NextSIM은 KAIST AIxMobility Lab에서 개발한 하이브리드 교통 시뮬레이터입니다. 하나의 네트워크에 미시(micro) 모형과 중시(meso) 모형을 함께 적용하며, 입력 데이터 편집부터 시뮬레이션 실행과 결과 재생까지 모든 작업을 브라우저에서 진행할 수 있습니다.

A hybrid traffic simulator from the KAIST AIxMobility Lab. It runs microscopic and mesoscopic models together in one network, and you edit the inputs, run, and replay the results in the browser.

필요한 곳만 차량 단위로 계산합니다Vehicle-level detail only where it matters

도시 전체를 차량 단위로 계산하면 시간이 너무 오래 걸리고, 모든 구간을 집계 모형으로 계산하면 특정 교차로에서 어떤 현상이 일어나는지 파악할 수 없습니다. NextSIM에서는 링크와 시간대마다 적용할 모형을 따로 지정할 수 있으며, 두 모형이 만나는 경계에서는 엔진이 차량을 한 모형에서 다른 모형으로 자동으로 옮깁니다.

Simulating a whole city car by car is slow; simulating all of it in aggregate hides what happens at the one intersection you are studying. NextSIM lets you choose the model per link and per time period, and the engine hands vehicles across the boundary.

계산 대상Represents
차로를 주행하는 각 차량의 위치·속도·가속도Each vehicle's position, speed, and acceleration on its lane
모형Models
차량 추종 모형, 차로 변경 모형Car following, lane changing

결과Output

Meso 중시 모형mesoscopic

모형Models

주요 기능Features

‘소스 빌드’ 표시가 있는 기능은 Windows 설치 파일과 ZIP 배포판에 포함되어 있지 않으므로, 소스 코드를 직접 빌드해야 사용할 수 있습니다.

Features marked “source build” are not in the Windows installer or the ZIP package; build from source to use them.

링크별 모형 선택Micro or meso per link

링크와 시간대마다 micro 모형과 meso 모형 중 하나를 선택할 수 있습니다. 두 모형 사이를 이동하는 차량은 엔진이 자동으로 처리합니다.

Choose micro or meso for each link and time period. The engine moves vehicles between the two.

대중교통Public transit

버스·TRT·트램·철도 노선과 승객 수요를 도로 교통과 함께 시뮬레이션합니다. 정류장마다 기다리는 승객 수와 차내 승객 수는 BIMS 화면에서 확인할 수 있습니다.

Bus, TRT, tram, and rail lines and passenger demand run together with road traffic. Waiting and on-board passengers per stop appear in the BIMS view.

신호Signals

신호 현시와 신호 계획, 시간대별 운영 계획(TOD)을 편집할 수 있습니다.

Edit phases, signal plans, and time-of-day (TOD) schedules.

가상 검지기Virtual detectors

E1(지점)·E2(구간)·E3(영역) 검지기를 설치하여 교통량, 점유율, 통행시간을 현장 관측 자료와 같은 형식으로 수집합니다.

E1 (point), E2 (section), and E3 (area) detectors collect flow, occupancy, and travel time in the same form as field data.

실제 도로망 가져오기Real road networks

국가표준 노드링크 데이터나 OpenStreetMap 데이터로 네트워크를 생성한 뒤 바로 편집할 수 있습니다. 테스트에 쓸 무작위 네트워크도 생성할 수 있습니다.

Build a network from Korea's standard node-link data or OpenStreetMap and edit it right away, or generate a random one for testing.

동적 통행 배정(DTA)Dynamic traffic assignment (DTA) 미리보기preview

시뮬레이션을 반복 실행하면서, 기점과 종점 사이의 경로 선택 비율이 수렴할 때까지 통행을 배정합니다. 수렴 과정과 링크별·경로별 결과는 웹 화면에서 확인할 수 있습니다.

Repeat the simulation until route shares between origins and destinations converge, then look at the convergence and the link and route results in the browser.

NextCI 소스 빌드source build

TCP 통신으로 시뮬레이션을 한 스텝씩 진행하면서 상태를 조회할 수 있습니다. 강화학습 환경이나 다른 시뮬레이터와 연동할 수 있도록 Python 클라이언트를 제공합니다.

Step the simulation and query its state over TCP, with a Python client for reinforcement learning and co-simulation.

체크포인트Checkpoints 소스 빌드source build

원하는 시점의 시뮬레이션 상태를 저장해 두고 언제든 그 시점으로 되돌아갈 수 있습니다. 따라서 같은 시점에서 여러 제어안을 각각 실행하여 비교할 수 있습니다.

Save the state at any moment and come back to it to try several control strategies from the same point.

Edit 모드와 Run 모드Edit mode and Run mode

NextSIM은 하나의 화면에서 상단의 Edit과 Run을 선택하여 모드를 전환합니다. Edit 모드에서 입력 데이터를 만들어 저장한 뒤 Run 모드에서 실행하면, 차량·승객 경로 계산(RouteGenerator)과 시뮬레이션이 차례로 진행됩니다. 시뮬레이션 결과도 같은 화면에서 재생할 수 있습니다.

One NextSIM screen, switched between Edit and Run at the top. Build and save the inputs in Edit mode, then run them in Run mode: route calculation (RouteGenerator) and the simulation run one after the other, and the result replays on the same screen.

Edit 모드Edit mode

시뮬레이션에 필요한 입력 데이터를 지도 위에서 직접 만들고 수정할 수 있습니다. 입력 파일 형식을 몰라도 편집할 수 있습니다.

Create and edit simulation inputs on the map, without learning the file formats.

  • 도로·차로·교차로 연결 편집, 노드링크·OSM 데이터 가져오기
  • OD 수요 입력과 시간대별 micro/meso 설정
  • 신호(현시·계획·TOD), 정류장, 대중교통 노선, 돌발 상황 편집
  • 저장할 때마다 자동으로 백업하고, 필요하면 이전 상태로 복원
  • 네트워크를 ZIP 패키지로 내보내거나 가져오기, 다른 이름으로 저장
  • Roads, lanes, and junction connections; import from node-link data or OSM
  • OD demand and micro/meso settings per time period
  • Signals (phases, plans, TOD), stops, transit lines, and incidents
  • An automatic backup on every save, restorable at any time
  • Export and import a network as a ZIP package, or save it under another name

Run 모드Run mode

시뮬레이션을 실행한 뒤, 결과를 지도 위에서 시간 순서대로 재생하며 분석할 수 있습니다.

Run a simulation, then replay the result on the map and inspect it over time.

  • 실행 중에도 현재까지 계산된 결과를 지도에서 미리 확인
  • 재생 속도 조절, 링크 혼잡도를 색상과 범례로 표시
  • 차량·링크·정류장을 클릭하여 상세 정보 확인, 시나리오별 요약 통계 제공
  • 버스 운행 정보(BIMS): 정류장별 대기 승객, 승하차 인원, 차내 인원
  • Preview a run on the map while it is still going
  • Playback speed; links coloured by congestion, with a legend
  • Click a vehicle, link, or stop for details; scenario summary statistics
  • Bus information (BIMS): waiting, boarding, alighting, and on-board passengers per stop

설치Install

NextSIM은 네 가지 방법으로 설치할 수 있으며, 어떤 방법으로 설치하더라도 브라우저에서 사용하는 기능은 같습니다. Windows 사용자라면 설치 파일을 이용하는 방법이 가장 간단합니다.

There are four ways to install, and all of them run the same NextSIM in the browser. On Windows, the installer is the simplest.

Windows 설치 파일Windows installer

Windows 10/11 64비트에서 사용할 수 있습니다. 설치 프로그램의 안내에 따라 진행하면 되며, Python이나 WSL, Docker를 따로 설치할 필요가 없습니다.

For 64-bit Windows 10 and 11. Follow the installer; no Python, WSL, or Docker needed.

NextSim-Setup-v1.2.exe

Docker

Docker가 설치되어 있다면 운영체제와 관계없이 사용할 수 있습니다. 명령어 하나로 엔진 빌드부터 웹 서버 실행까지 진행됩니다. 이 방법을 사용하려면 소스 저장소 접근 권한이 필요합니다.

Anywhere Docker runs. One command builds the engine and starts the web server. Needs access to the source repository.

docker compose up --build

Linux·WSL 배포판Linux and WSL package

미리 빌드된 ZIP 파일의 압축을 풀고 스크립트 하나만 실행하면 됩니다. 별도로 컴파일할 필요가 없습니다.

Unpack the prebuilt ZIP and run one script. No compiler needed.

./start_web.sh

소스에서 빌드Build from source

엔진을 수정하거나 NextCI를 사용하려면 소스 코드를 직접 빌드해야 합니다. 이 방법을 사용하려면 소스 저장소 접근 권한이 필요합니다.

To change the engine or use NextCI. Needs access to the source repository.

cmake --preset release -S Captain

어떤 방법으로 설치하든 AVX2를 지원하는 x86-64 CPU가 필요합니다. 2013년 이후 출시된 인텔·AMD CPU는 대부분 AVX2를 지원합니다.

Every method needs an x86-64 CPU with AVX2 (most Intel and AMD CPUs since 2013).
