ScenarioLab

새 교통 기능을 코딩 없이 설정하고 실험합니다.Configure and test traffic features without writing code.

ScenarioLab은 V2X, 주행 안내(Guidance), 제어권 전환(TOR) 같은 교통·차량 기능을 직접 설정하고 시험해 보는 시나리오 실험 환경입니다. NextSIM이 제공하는 기능을 고르고 파라미터만 조정하면, 새 기능을 직접 코딩하지 않아도 시뮬레이션으로 효과를 확인할 수 있습니다.

ScenarioLab is a scenario lab for traffic and vehicle features such as V2X, guidance and take-over requests (TOR). Pick a feature NextSIM provides, adjust its parameters, and see its effect in simulation without writing code.

ScenarioLab은 현재 개발하고 있는 모듈입니다.

ScenarioLab is under development.

기능 설명 영상을 준비하고 있습니다.A walkthrough video is coming soon.

실험 과정이 하나의 화면에서 이어집니다One screen, from setup to comparison

결과 기록을 따로 찾아볼 필요 없이, 기능 선택부터 시나리오 비교까지 한 화면에서 진행합니다.

No digging through result logs: the whole experiment, from choosing features to comparing scenarios, happens on one screen.

  1. 1기능 선택Choose features실험할 기능을 고릅니다. 여러 기능을 함께 켤 수도 있습니다.Pick the features to test; several can be on at once.
  2. 2파라미터 설정Set parameters통신 범위, 순응률처럼 기능마다 필요한 값을 정합니다.Set values such as communication range or compliance rate.
  3. 3시나리오 실행Run scenarios설정을 바꾼 여러 시나리오를 실행합니다.Run scenarios with different settings.
  4. 4이벤트 확인Check events통신, 안내, 제어권 전환이 언제 어디서 일어났는지 확인합니다.See when and where messages, guidance and take-overs happened.
  5. 5결과 분석Analyse results기능이 교통 흐름과 안전에 준 영향을 살펴봅니다.Look at the effect on traffic flow and safety.
  6. 6시나리오 비교Compare scenarios값을 바꿔 실행한 시나리오의 결과를 나란히 비교합니다.Compare the runs side by side.

ScenarioLab

특정 기능이나 특정 구간을 대상으로 기능을 검증하고 실험하는 데 집중합니다. 예를 들어 V2X 통신 범위를 다르게 설정한 시나리오 여러 개를 실행해 결과를 비교하거나, 주행 안내 순응률에 따라 교통 흐름이 어떻게 달라지는지 비교할 수 있습니다.

Focuses on testing one feature or one stretch of road. Run several scenarios with different V2X ranges and compare them, or see how traffic changes with the guidance compliance rate.

기본으로 제공하는 기능Built-in features

첫 버전에서는 다음 세 가지 기능을 제공하며, 기능마다 아래 항목을 설정할 수 있습니다.

The first version comes with three features, each with the settings below.

V2XV2X

  • 통신 가능 범위
  • 지연 시간(Latency)
  • 패킷 손실(Packet loss)
  • 적용 차량
  • 메시지 유형
  • RSU 적용 범위
  • Communication range
  • Latency
  • Packet loss
  • Equipped vehicles
  • Message type
  • RSU coverage

주행 안내(Guidance)Guidance

  • 안내 적용 구역
  • 대상 차량
  • 안내 정보 종류
  • 순응률(Compliance rate)
  • 경로·차로 변경 안내
  • Guidance zone
  • Target vehicles
  • Kind of information
  • Compliance rate
  • Route and lane-change guidance

제어권 전환(TOR)Take-over request (TOR)

  • TOR 발생 구역
  • 발생 조건
  • 제어권 전환 허용 시간(Take-over time budget)
  • 운전자 반응 시간
  • 성공·실패 조건
  • Where TORs occur
  • Trigger conditions
  • Take-over time budget
  • Driver response time
  • Success and failure conditions

각 기능은 켜고 끌 수 있으며, 여러 기능을 함께 켜서 복합 시나리오를 구성할 수도 있습니다.

Each feature can be switched on or off, and several can be combined into one scenario.
